Visão geral

Tudo do portal roda num único servidor. A equipe chega a ele pela Cloudflare, e o Claude cuida dele por SSH. O caminho em dourado é o de uma mudança, do pedido ao ar.

O Monday também avisa o portal quando um quadro muda, pelos webhooks dos quadros AAAF e HFA.

Publicar uma mudança

Toda mudança passa pelo Claude e chega ao ar sozinha, cerca de 5 minutos depois que ele envia ao GitHub.

  1. Abra o app Claude, aba Code, no projeto TN Op Portal.

  2. Descreva o que quer, em português. Para uma mudança grande e visível, o Claude mostra antes como vai ficar e pergunta se pode publicar.

  3. O Claude altera o código e roda as checagens: os tipos e cerca de 900 testes automáticos.

  4. Ele grava a mudança (commit) e envia ao GitHub (push), sempre na branch main. Existe só essa branch.

  5. O GitHub roda o "Deploy to the portal's server": entra no servidor, monta a versão nova e troca a antiga por ela. Se a nova não responder, o servidor volta sozinho para a anterior.

  6. Para conferir, abra a aba Actions do repositório: verde significa no ar. Ou pergunte ao Claude qual versão está no ar.

Mudanças no banco de dados (as migrations) o Claude aplica direto no servidor. Antes da mudança, era você quem rodava no painel do Supabase; isso acabou.

Voltar uma versão: peça ao Claude. Ou, na aba Actions, abra "Deploy to the portal's server", clique em Run workflow e informe o código (sha) de um commit anterior.

Cuidado: cada push no main vai direto para o ar, e não há um ambiente de teste separado. O endereço staging.truenorthportal.online mostra o mesmo portal. Se algum dia outra pessoa puder enviar código para o portal, proteja o main antes, com branch e pull request.

Backups

Todas as noites, às 03:30 (horário do leste dos EUA), o servidor guarda três cópias. A restauração foi testada em 5 de outubro com os dados reais, e as 94 tabelas voltaram idênticas.

Os backups ficam em /home/tnportal/portal-backups, no servidor. Essa pasta entra no backup diário da própria ScalaHosting, então cada noite também fica guardada fora do servidor.

Restaurar: peça ao Claude, dizendo de qual dia. O procedimento está em deploy/README.md, seção Backups.

O código não depende desses backups: ele vive no GitHub, com todo o histórico. As ferramentas do COE têm uma cópia congelada de 6 de outubro em TrueNorthDM-Archive.

Pessoas

No portal só entra quem um admin convidou, sempre com o email da GoodNews, e todo mundo usa o 2FA. No GitHub, só entra quem você convida para a TrueNorthDM, e cada um vê apenas os repositórios que você liberar.

Regras do login: código de 6 dígitos por email, depois o código do app autenticador. A sessão dura até 2 meses, ou 15 dias sem uso. Quem entra pela primeira vez tem 7 dias para configurar o 2FA; quem já tinha conta tem até 13 de outubro.

No GitHub

  • Convidar: em People, clique em Invite member, use o email ou o username e escolha Member, nunca Owner.
  • Liberar um repositório: no repositório, Settings, Collaborators and teams, Add people. Read só vê o código; Write pode enviar código.
  • Tirar o acesso: em People, clique na pessoa e depois em Remove from organization. Corta tudo de uma vez.
  • Nunca compartilhe o login da conta truenorthdigitalmarketing. Ela é a dona de tudo.

A organização já está fechada: membros novos não veem nada até você liberar, não criam nem copiam repositórios, e o 2FA do GitHub é obrigatório.

Glossário

Branch
Uma linha de trabalho do código. O portal usa só a main.
Commit
Uma mudança gravada no histórico do código, com data e descrição.
Container
Uma caixa isolada no servidor onde roda um programa: o portal, o banco, o login.
Cron
Uma tarefa que o servidor roda sozinho em horário marcado.
Deploy
Colocar uma versão nova do portal no ar.
DNS
O catálogo que diz a que servidor um endereço leva. O nosso fica na Cloudflare.
Docker
O programa que roda os containers.
Migration
Uma mudança na estrutura do banco de dados.
Organização
O espaço da empresa no GitHub, com membros e permissões.
Proxy
O porteiro que recebe quem acessa o endereço e repassa ao portal.
Pull request
Um pedido para juntar uma branch à main, revisado antes.
Push
Enviar ao GitHub os commits feitos no Mac.
Repositório
A pasta de um projeto no GitHub, com todo o histórico.
SSH
O jeito seguro de entrar no servidor por linha de comando.
Supabase
O conjunto que dá ao portal banco, login e arquivos. Roda dentro do nosso servidor.
Token
Uma senha para programas, que dá acesso a um serviço.
VPS
Um servidor alugado só para nós. O nosso está na ScalaHosting.
Webhook
Um aviso automático que um serviço manda ao portal quando algo muda. O Monday faz isso.
2FA
O segundo passo do login: o código do app autenticador no celular.
