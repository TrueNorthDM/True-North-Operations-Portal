# Writing style

Never use an em dash (the "—" character) anywhere: not in user-facing copy, not in code comments, not in commit messages, not in docs. Use a comma, colon, period, parentheses, or a plain hyphen ("-"), whichever reads best. This is a hard rule for every string the product renders and for all source comments.
